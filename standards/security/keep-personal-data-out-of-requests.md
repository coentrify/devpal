# Keep Personal Data Out Of Requests

No personal data of the director's goes into a web request an agent makes: a name, an email address or an account id, in the URL, a header, a User-Agent or the body.

## Why

The director's personal data stays with the director.

## How To Apply

- A service that asks automated clients for contact details gets a generic client name, or the agent asks the director first.
- A request the director asked for, with their own data, is the director's call and goes as asked.
