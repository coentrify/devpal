# Project Lifecycle

A project is in one phase at a time, and the phase decides what matters now.

## Why

The same work is right in one phase and wasted in another.

## How To Apply

- Name the phase the project is in.
- State the goal of the current phase, and keep the work on that goal.
- File what does not serve the current phase for a later one: a ticket for the next phase, an idea in the dump beyond it.
- A phase ends at a phase gate: a leading question together with everything it takes to answer it. The answer sends the project on or back a phase.
- A game follows the Game Phases, in four stages.
- A web product can go from a prototype to a skeleton, a design and production.
- A product in production is live, and most web projects are from the start: what ships is polished.
