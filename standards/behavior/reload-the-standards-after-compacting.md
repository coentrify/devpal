# Reload The Standards After Compacting

After a compaction, read the Core Rules again.

## Why

An agent works from the standards themselves, at every point in a session.

## How To Apply

- Read again any other standard the work at hand needs.
- Where the agent does not read its entry point again after a compaction, and supports hooks, let a hook reload the Core Rules, so no step depends on remembering.
