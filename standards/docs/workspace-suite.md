# Workspace Suite

A coentrified workspace grows until it holds every deliverable of the suite. A missing item becomes work the way [Workspace Template](workspace-template.md) says.

## Why

A workspace should know what complete looks like.

## The Suite

- Documentation
- READMEs
- Unit tests
- E2E tests
- UI styleguide
- Component library
- Design system
- Reports
- Docs wiki
- Demo videos
